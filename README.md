## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/poonia2000tushar-wq/Portfolio.git
cd Portfolio

# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Deploy to GitHub Pages
npm run deploy
```
